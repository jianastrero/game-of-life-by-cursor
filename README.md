# Game of Life

A Kotlin implementation of Conway's Game of Life, created using [Cursor](https://cursor.sh/).

## About

This project implements Conway's Game of Life, a cellular automaton devised by mathematician John Conway. The game is a zero-player game, meaning its evolution is determined by its initial state, requiring no further input.

## Project Structure

- `src/` - Contains the source code
- `build.gradle.kts` - Gradle build configuration
- `settings.gradle.kts` - Gradle settings

## Development

This project was created and developed using Cursor, an AI-powered code editor that enhances the development experience with intelligent code completion and assistance.

## Requirements

- Kotlin
- Gradle
- JDK 8 or higher

## Building

To build the project, run:
```bash
./gradlew build
```

## Running

To run the project, use:
```bash
./gradlew run
```
